# Horloges du monde / World clock

Comparez quatre villes avec les fuseaux et changements d’heure automatiques.

Compare four cities with automatic time zones and daylight saving changes.

Configuration is stored by DashDock. Preview edits are temporary. No network services or additional permissions are required.
Configure one to four IANA zones in the settings sheet. Calendar day differences are relative to your browser time zone; Intl handles DST.
