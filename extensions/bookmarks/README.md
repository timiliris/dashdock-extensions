# Favoris / Bookmarks

Install this extension from the DashDock store. Open its settings sheet to add, edit or delete up to 12 HTTP(S) links. Categories and search help organize services; four links are shown per page. URLs containing credentials or unsafe schemes are rejected. Links open in a new tab with `noopener noreferrer`; no remote icons or requests are used.

Configuration is saved per widget through `config.get` and `config.save`. Preview mode cannot write. French/English labels, colors, fonts and light/dark themes follow DashDock. Permission: `links` (open links outside the sandbox).
