# Habitudes / Habits

Independent extension with no network permissions or dependencies. Configure up to six habits in the side settings panel; mark today's habits on the dashboard. Three habits per page keep the card compact.

Dates use the **browser's local calendar**, including daylight saving changes. Changing time zone can change which date counts as today. The seven bars represent the last seven dates, ending today. Hover a bar for its date and completion state. The streak includes consecutive checked dates ending today, or yesterday when today is not checked yet; it is capped by the saved 60-day history. Missing dates are unchecked. No historical completions are invented.

Each widget saves its own configuration. At most 60 calendar days per habit are retained; old dates are discarded on the next save. Preview changes are temporary. Loading failures block writes until Retry succeeds. Save failures retain the settings draft and leave the previous check state intact.
