# Convertisseur / Unit converter

Convertissez longueur, masse, température et stockage, sans connexion.

Convert length, mass, temperature and storage, entirely offline.

Configuration is stored by DashDock. Preview edits are temporary. No network services or additional permissions are required.
Comma and decimal point inputs are accepted, including scientific notation. Ambiguous grouping separators are rejected. SI storage units use 1000, IEC units use 1024. Temperatures below absolute zero are rejected. Results show up to ten significant digits. Category, units and input are saved after a brief pause.
